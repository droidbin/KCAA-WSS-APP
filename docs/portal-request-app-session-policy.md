# 포털 요청 사항: 안드로이드 앱 세션 유지 정책 (사내/외부 IP)

앱 v1.7.1 에서 앱 종료 시 세션이 폐기되도록 변경했습니다. 포털 서버가 아래 내용을 처리해야 정책이 완성됩니다.

## 배경
- 앱은 WebView 쿠키가 곧 로그인 세션이며, 접속 IP나 승인 상태를 알지 못합니다.
- 앱 v1.7.1 은 앱 프로세스 시작 시, 그리고 사용자가 앱을 종료할 때 **세션 쿠키(Max-Age/Expires 없는 쿠키)를 제거**합니다.
- 따라서 쿠키 수명으로 정책을 전달하면 앱 쪽 추가 API 없이 동작합니다.

## 요청 1. 쿠키 수명 분기 (필수)
앱 요청(User-Agent 에 `KCAAWssAndroid/` 포함)의 로그인 세션 쿠키를 아래와 같이 발급해 주세요.

**User-Agent 정확한 형식** (앱 v1.7.1 기준, 코드 확인 완료)
- 웹뷰 페이지 요청: 기본 WebView UA 뒤에 공백 + 토큰이 붙습니다.
  `Mozilla/5.0 (Linux; Android 14; ...) AppleWebKit/537.36 (KHTML, like Gecko) Version/4.0 Chrome/... Mobile Safari/537.36 KCAAWssAndroid/1.7.1`
- 앱 네이티브 API(`/api/push/*`): UA 가 토큰만 단독으로 전송됩니다. `KCAAWssAndroid/1.7.1`
- 토큰 형식은 `KCAAWssAndroid/{versionName}` (예: `1.7.1`, 숫자 3자리 `Major.Minor.Patch`, 디버그/릴리스 동일, 접미사 없음).
- 판별은 대소문자 구분 부분 문자열 `KCAAWssAndroid/` 포함 여부 또는 정규식 `\bKCAAWssAndroid/(\d+\.\d+\.\d+)$` 로 하면 됩니다. (웹뷰는 UA 끝, 네이티브는 UA 전체)
- 버전은 앱 업데이트마다 바뀌므로 특정 버전에 고정하지 마세요. 세션 쿠키 분기는 `/api/push/*` 가 아닌 웹뷰 로그인 요청 기준입니다.
- UA 는 클라이언트가 임의로 흉내 낼 수 있으므로 보안 경계로 쓰지 말고, 쿠키 수명 분기(앱 종료 시 세션 쿠키 폐기 동작 유도) 용도로만 사용해 주세요.

| 상태 | 세션 쿠키 |
|---|---|
| 사내 IP 접속 | `Max-Age` 가 있는 영구 쿠키 (승인 불필요) |
| 외부 IP + 관리자 승인 완료 | `Max-Age` 가 있는 영구 쿠키 |
| 외부 IP + 미승인 | `Max-Age`/`Expires` 없는 세션 쿠키 |

- 미승인 세션 쿠키에 `Max-Age`/`Expires` 가 붙으면 앱 종료 후에도 유지되므로 반드시 제외해 주세요.
- 기존 쿠키 속성(`Secure`, `HttpOnly`, `SameSite`)은 그대로 유지해 주세요.

## 요청 2. 승인 시 쿠키 승격
- 관리자가 외부 IP 세션을 승인하면 영구 쿠키로 재발급해 주세요. 앱을 종료하지 않아도 이후 요청의 응답 `Set-Cookie` 로 승격되면 됩니다.
- 승인 철회·만료 시 서버에서 해당 세션을 무효화해 주세요.

## 요청 3. IP 재평가 정책 결정
- 사내 IP 에서 로그인한 영구 세션을 외부 IP 에서 사용할 때 허용할지, 재승인을 요구할지 정해 주세요. (권장: 외부 IP 요청은 승인 상태를 다시 확인)
- 사내 IP 판별 시 프록시 헤더(`CF-Connecting-IP` 등) 기준을 명확히 해 주세요.

## 요청 4. 푸시 관련 쿠키는 변경하지 않음
- `kcaa_app_device` (Max-Age 1년) 는 세션 쿠키가 아니므로 앱 종료 후에도 유지되어 푸시 등록이 유지됩니다. 이 쿠키는 그대로 두어 주세요.

## 앱 동작 참고 (사용자 안내용)
- 외부 IP 미승인 사용자는 앱을 종료하거나 메모리 부족으로 프로세스가 종료되면 다시 로그인해야 합니다.
- 미승인 상태에서 푸시 알림으로 앱이 새로 시작되면 로그인 화면이 표시됩니다.

## 확인 시나리오
1. 사내 IP: 로그인 → 앱 스와이프 종료 → 재실행 시 로그인 유지
2. 외부 IP 미승인: 로그인 → 스와이프 종료 → 재실행 시 로그아웃
3. 외부 IP 승인 후: 재실행 시 로그인 유지, 푸시 등록 유지
