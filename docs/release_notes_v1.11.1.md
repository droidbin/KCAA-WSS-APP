## 관리자 로그인 표시 수정, 로그아웃 버튼

### 바뀐 점
- **관리자 로그인 상태가 항상 "로그아웃"으로 보이던 문제 수정**: 실제 관리자 세션을 기준으로 상태를 확인합니다. 관리자 페이지에서 로그인해도 설정 화면에 바로 반영됩니다.
- **로그아웃 버튼 추가**: 설정 첫 화면 맨 아래에 직원·관리자 모두 쓸 수 있는 [로그아웃] 버튼이 생겼습니다. 이 기기의 포털 로그인(관리자 로그인 포함)을 해제하고 포털을 다시 시작합니다.

### 업데이트 안내
- 사내 네트워크에서는 로그아웃 후 다시 열면 자동으로 인증됩니다. 외부 접속은 다시 인증이 필요할 수 있습니다.
