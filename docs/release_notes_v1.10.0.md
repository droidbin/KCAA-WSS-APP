## 새 기기 승인 요청 알림

### 바뀐 점
- **새 기기 승인 요청 알림(관리자)**: 회사 밖에서 인증을 마친 새 기기가 승인을 기다리면 통합·일반 관리자 기기에 알림이 옵니다. 알림을 누르면 포털의 기기 승인 화면이 열립니다. 설정 > 알림의 [새 기기 승인 요청]에서 끄고 켤 수 있습니다.
- **승인 대기 중 뒤로가기 보호**: 승인 대기 화면에서 뒤로가기를 눌러도 포털을 벗어나지 않고 "한 번 더 누르면 종료" 안내만 나옵니다.

### 업데이트 안내
- 새 기기 승인 요청 알림은 포털 서버에서 앱 알림을 켠 뒤부터 도착합니다.

### 설치 파일
- `kcook_wss_v1.10.0.apk`: 사내 배포용 정식 릴리스 APK
- `app-release.aab`: Google Play Console 등록용 번들
