# 앱 → 포털 요청: 성명·이메일 인증을 로그인 유지 조건으로 추가

대상: 포털·증명서 작업 세션
앱 버전: v1.9.0 (versionCode 21)
관련 문서: `portal-request-app-session-policy.md`, `app-reply-app-session-policy.md`

## 1. 배경
- 현재 로그인 유지 조건은 사내 IP 또는 관리자 승인 기기입니다.
- 추가: **포털 메인에서 성명·이메일 인증을 완료한 기기**도 로그인을 유지합니다.
- 인증으로 "누가 어떤 기기로 접속했는지" 서버가 알 수 있게 됩니다.
- 인증 완료 기기는 증명서 시스템의 추가 이메일 인증을 면제합니다.
- 앱은 기존대로 쿠키 수명만 따릅니다. (앱이 하는 일: 앱 종료 시 세션 쿠키 폐기)

## 2. 포털에 요청할 사항
1. **인증 기록 저장**: 성명·이메일 인증 완료 시 기기 쿠키 `kcaa_app_device` 와 인증 정보(성명, 이메일, 인증 시각)를 연결해 저장해 주세요.
2. **영구 쿠키 발급**: 인증 완료 기기에는 앱 UA 요청에 `Max-Age` 있는 영구 세션 쿠키를 발급해 주세요. (사내 IP·승인 기기와 같은 경로). 미인증 외부 기기는 지금처럼 세션 쿠키.
3. **증명서 연동**: 증명서 서버가 `kcaa_app_device` 로 포털 인증 기록을 조회해 인증된 기기면 추가 이메일 인증을 면제해 주세요.
   - 호스트가 달라 쿠키·sessionStorage 는 공유되지 않습니다. 앱은 `kcaa_app_device` 를 포털·증명서 등 신뢰 호스트 모두에 같은 값으로 심습니다.
4. **관리자 화면**: 기기별 접속자(성명, 이메일, 기기 번호)를 조회하고, 인증을 철회하면 영구 발급을 중단해 주세요.
5. **앱 표시용 API (신규)**: `GET /api/app/verification`
   - 인증: `Cookie: kcaa_app_device=<값>` (UA `KCAAWssAndroid/<버전>`)
   - 응답: `{"verified": true, "name": "홍길동"}` / `{"verified": false}` (이메일은 내려주지 마세요)
   - 앱은 설정 > 정보 > "포털 인증" 행에 `인증됨: 홍길동` / `미인증` 을 표시합니다. 404 등 미지원이면 행을 숨깁니다.
6. **개인정보**: 기기 식별자와 이메일을 묶으므로 보관 기간·파기 기준을 정해 주세요.

## 3. 앱 참고 정보
- 기기 번호: SHA-256(`kcaa_app_device` 값, UTF-8)의 앞 8자리. 설정 > 정보에 표시됩니다.
- 앱을 삭제하면 기기 쿠키가 새로 만들어져 다시 인증이 필요합니다. (앱 안내 문구 포함)
- 앱 종료 시 쿠키 처리: 세션 쿠키(Max-Age 없음)만 폐기, 기기 쿠키(1년)는 유지.

## 4. 실기기 확인 시나리오
1. 외부 IP·미인증 → 로그인 → 앱 종료 → 재실행: 로그아웃.
2. 포털 메인에서 성명·이메일 인증 → 앱 종료 → 재실행: 로그인 유지.
3. 인증 후 증명서 시스템 진입: 추가 이메일 인증 없음.
4. 설정 > 정보에서 "포털 인증: 인증됨: 성명" 표시, 관리자 화면에 같은 기기 번호로 접속자 표시.
5. 인증 철회 후 앱 종료·재실행: 로그아웃.
