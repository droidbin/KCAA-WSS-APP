## 관리자 화면 개편과 앱 글꼴 적용

### 바뀐 점
- **관리자 페이지 열기 버튼**: 설정 첫 화면과 관리자 화면 맨 위에 "관리자 페이지" 카드가 생겼습니다. [관리자 페이지 열기]를 누르면 관리자 페이지로 이동하고, 로그인되어 있지 않으면 로그인 화면으로 이어집니다. 현재 로그인 상태(통합 관리자 / 일반 관리자 / 로그아웃)도 카드에서 확인할 수 있습니다.
- **관리자 화면 모바일 개편**: 포털 화면과 어울리는 카드 형태로 다시 구성했습니다. 의무교육 URL, Slack 알림, 공지 푸시, 게시글 휴지통, 인사관리, 재고관리 바로가기가 카드로 정리되고, 관리자 로그아웃은 별도 버튼으로 분리했습니다.
- **앱 글꼴 적용**: 포털 웹 화면과 같은 Pretendard 글꼴을 앱 설정 화면과 안내 창에도 적용했습니다.

### 업데이트 안내
- 글꼴이 포함되어 설치 파일 크기가 약 2~3MB 늘었습니다.
- 관리자 로그인 화면은 포털 쪽 개편 후에 새 디자인으로 바뀔 예정입니다.

### 설치 파일
- `kcook_wss_v1.9.1.apk`: 사내 배포용 정식 릴리스 APK
- `app-release.aab`: Google Play Console 등록용 번들
