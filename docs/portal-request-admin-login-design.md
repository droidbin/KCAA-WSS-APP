# 포털 요청: 관리자 로그인 페이지를 새 디자인 언어로 통일

대상: 포털 저장소(`droidbin/gwangju-work-portal`) 작업 세션
작성: 앱 저장소 작업 세션 (앱 v1.9.1 기준, 2026-11-14)
우선순위: 보통 (기능 문제는 없고 화면이 어울리지 않는 문제)

## 1. 배경
앱 v1.9.1에서 설정·관리자 화면을 포털 디자인 언어(`DESIGN.md`)로 다시 만들었고, 관리자 화면 맨 위에 **[관리자 페이지 열기]** 버튼을 두었습니다. 이 버튼은 포털 `/admin`을 앱 안에서 열며, 로그인되어 있지 않으면 `/admin/login`으로 이동합니다. 그런데 이 로그인 화면이 포털 개편 이전 스타일 그대로라, 앱 설정 화면(새 스타일)에서 누르면 갑자기 다른 화면이 나타납니다. 모바일(390px)에서 직접 확인했습니다.

## 2. 현재 상태 (2026-11-13, 운영 `/admin/login`, 390×844 실측)
| 항목 | 현재 값 | 새 디자인 언어(`DESIGN.md`) |
|---|---|---|
| 페이지 배경 | `#f3f6fa` | `--page` `#f6f7f9` |
| 주요 버튼 | 배경 `#245f9c`, 모서리 8px, 글자 13px/400, 높이 43px | `--accent` `#2563eb`, 모서리 10px, 14px/700, 높이 46px |
| 입력창·선택창 | 기본 브라우저 스타일(모서리 0, 테두리 `#767676`) | 높이 46px, 테두리 `--input-line` `#d0d5dd`, 모서리 10px, 포커스 `--accent` + `0 0 0 3px #2563eb1f` |
| 글꼴 | `system-ui` | `Portal`(Pretendard), 대체 `-apple-system … "Malgun Gothic"` |
| 제목 h1 | 32px/700 | 모바일 28px/700, 자간 -.04em |
| 카드 | 흰 카드, 큰 모서리, 테두리·그림자 없음 | `--radius-lg` 16px, 1px `--line` 테두리, `--shadow-card` |
| 링크 `업무지원포털` | 브라우저 기본 파란 밑줄 | 보조(테두리) 버튼 또는 `--accent` 링크 |
| 상단바·푸터 | 없음 | 공통 셸(`kcaa-shell.css`): 흰 상단바 + 학교 심볼 + 시스템 이름, 푸터 |

## 3. 요청 사항
1. `/admin/login`(통합 관리자 로그인)을 다른 시스템과 같은 **공통 셸 + 새 토큰**으로 통일합니다. 마크업은 포털 `DESIGN.md`의 "공통 셸" 예시를 따르고, 스타일은 `shared/kcaa-shell/kcaa-shell.css`를 사용합니다. (`node scripts/sync-shell.mjs`로 사본 동기화, 정적 경로 허용 목록·`_routes.json`에 `/brand/kcaa-shell.css`와 `/fonts/*` 추가)
2. 입력창·선택창·버튼은 `DESIGN.md`의 입력창/주요 버튼 규격을 따릅니다. 모바일 터치 영역은 44px 이상.
3. 로그인 유형 선택(통합 관리자 / 그 외 관리자)과 비밀번호 입력, 오류 문구는 **동작을 바꾸지 않습니다**. 오류는 `--danger` 글자로 입력창 아래 한 줄.
4. `returnTo` 파라미터(`/admin`, `/admin/inventory` 등)와 로그인 후 이동은 지금과 같게 유지합니다.
5. 같은 로그인 화면을 쓰는 다른 진입점도 함께 확인합니다: 재고관리(`gwangju-inventory.pages.dev`)는 로그인 없이 열면 `/admin/login?returnTo=%2Fadmin%2Finventory`로 이동하며 같은 화면을 보입니다.

## 4. 앱 쪽 전제 (바꾸지 말아 주세요)
- 앱 WebView의 User-Agent에 `KCAAWssAndroid/<버전>`이 붙습니다. 이 값으로 앱 전용 처리를 하지 않아도 되지만, 기존 규칙은 유지해 주세요.
- 앱은 로그인 화면에서 `portal_custom.css`를 덧입히지만 로그인 페이지 마크업(폼 필드 이름, `#` ID)에 의존하지 않습니다. 폼 구조를 바꿔도 앱 수정은 필요 없습니다.
- 앱이 여는 주소: `https://gwangju-work-portal.pages.dev/admin` (로그인 상태면 관리자 콘솔, 아니면 로그인 화면).

## 5. 확인 방법 (포털 쪽)
- 390px·375px·1440px에서 로그인 화면이 상단바·카드·버튼·입력창 규격에 맞는지 실측(`DESIGN.md`와 같은 방식).
- 잘못된 비밀번호, 빈 값, 로그인 성공 후 `returnTo` 이동이 이전과 같은지 확인.
- 앱 설정 → 관리자 → [관리자 페이지 열기]로 열었을 때(앱 v1.9.1) 화면이 어울리는지 확인(실기기 확인은 앱 쪽에서 합니다).
