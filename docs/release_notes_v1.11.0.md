## SMB Manager 요청 알림

### 바뀐 점
- **SMB Manager 요청 알림(통합 관리자)**: 직원이 SMB Manager로 PC 등록, 정보 정정, 신고를 요청하면 통합 관리자 기기에 알림이 옵니다. 알림에는 요청 내용 없이 종류와 건수만 표시됩니다. 설정 > 알림의 [SMB Manager 요청]에서 끄고 켤 수 있습니다.
- **관리자 웹은 브라우저로 열림**: 알림을 누르면 SMB 관리자 웹이 앱이 아닌 기본 브라우저에서 열립니다. 로그인(Cloudflare Access)은 브라우저에서 진행됩니다.

### 업데이트 안내
- 통합 관리자 기기에만 알림이 전달됩니다. 일반(열람) 관리자와 직원에게는 설정 항목이 보이지 않습니다.
- 앱 알림은 포털 서버에서 앱 전송을 켠 뒤부터 도착합니다.

### 설치 파일
- `kcook_wss_v1.11.0.apk`: 사내 배포용 정식 릴리스 APK
- `app-release.aab`: Google Play Console 등록용 번들
