## 운영 감시·로그인 만료 안내 알림

### 바뀐 점
- **운영 감시 알림(통합 관리자 전용)**: 포털·서비스 운영 감시에서 이상이 감지되면 관리자 알림 채널로 알려 줍니다. 알림을 누르면 해당 화면이 앱에서 열립니다.
- **로그인 만료 안내 알림**: 이메일 인증 회원과 관리자의 포털 로그인이 하루 뒤 만료되기 전에 미리 알려 줍니다.

### 업데이트 안내
- 두 알림 모두 설정 > 알림에서 종류별로 켜고 끌 수 있습니다. 운영 감시 알림은 통합 관리자로 로그인한 기기에만 표시됩니다.
- 업데이트 전 앱에서는 이 알림들이 일반 알림으로 표시됩니다.

### 설치 파일
- `kcook_wss_v1.12.0.apk`: 사내 배포용 정식 릴리스 APK
- `app-release.aab`: Google Play Console 등록용 번들
