## 포털 기기 인증과 증명서 연동

### 바뀐 점
- **포털 인증 상태 표시**: 설정 > 정보에 [포털 인증]이 표시됩니다. 포털 메인에서 성명·이메일 인증을 마친 기기는 `인증됨: 성명`으로 보입니다.
- **로그인 유지 조건 추가**: 사내 네트워크에서 성명·이메일 인증을 마친 기기는 앱을 닫아도 로그인이 유지됩니다. 외부에서 인증한 기기는 성명·이메일이 기록되고, 관리자 승인 후 로그인이 유지됩니다.
- **증명서 추가 인증 면제**: 인증된 기기는 증명서 시스템에서 이메일 인증번호 없이 이용할 수 있습니다. (포털 서버 기능)
- **안내 문구 정리**: 외부 접속 시 관리자 승인 전에는 앱을 닫으면 다시 로그인해야 한다는 안내를 정리했습니다.

### 업데이트 안내
- 인증은 포털 메인 화면 아래의 [기기 인증하기]에서 진행합니다. 이름, 회사 이메일, 인증번호(6자리)가 필요합니다.
- 앱을 삭제하면 기기 번호가 새로 만들어져 다시 인증해야 합니다.
- 포털 서버가 업데이트되기 전에는 [포털 인증] 행이 보이지 않습니다.
